# Сайт Ивана Трояновского

## Ветка `v2-minimal` — «золотая середина» (ТЗ: `../TZ-minimalism-v2.md`)

Сайт — портфолио. Меню: Портфолио · Обучение · Магазин · RU/EN.

```
index.html          главная-история в главах: Пролог → I Тишина → II До →
                    III Плёнка (лента одного ролика) → IV Как есть → V Свои →
                    VI Съёмки (портфолио: Сетка / Список / Галерея) → Эпилог
syomka.html?s=slug  страница съёмки — лента по шаблону, данные из shoots.js
story-zhenya-nikita.html  рукописная история (кадры теперь полноразмерные)
obuchenie.html      видеоурок (кнопка «Купить») и мастер-классы
magazin.html        отпечатки: один кадр — один экран, «Заказать отпечаток»
legacy/             заявка на съёмку и главная v1 — убрано, не удалено

assets/shoots.js    данные портфолио: 11 съёмок, 80 кадров (названия рабочие)
assets/works.js     три вида портфолио и переключатель внизу экрана
assets/roll.js      глава «Плёнка»: скролл ведёт ленту кадров вбок
assets/shoot.js     сборка ленты на syomka.html
assets/landing.css  стили глав и видов портфолио
img/s/<slug>/       кадры съёмок: NN.webp (1600px), m/ (960px), t/ (360px)
img/story/          кадры глав: Ваня за работой, сам Ваня, плёнка
```

## Админка

Локальная: работает на компьютере, где лежит этот репозиторий.

```bash
cd site
set ADMIN_PASSWORD=придумать-пароль      # Windows; на macOS/Linux — export
python admin/server.py
```

Открыть http://localhost:8200/admin/ — там же отдаётся весь сайт.

| Вкладка | Что правится |
|---|---|
| Съёмки | создать, порядок, название/город/год/адрес, вступление, «скрыть», согласие пары; кадры — перетащить пачкой (браузер сам режет 1600/960/360 webp), порядок, обложка, подписи, удаление |
| Главная | посыл, видео первого экрана (ссылка или загрузка файла), постер, тексты и кадры глав, «о себе», портрет, какой ролик в «Плёнке» |
| Магазин | вступление, работы: кадр, название, размер, тираж, цена, статус (в продаже / продано / скрыта) |
| Обучение | заголовок, вступление, видеоурок, ссылка оплаты, мастер-классы со статусом |
| Настройки | включить/выключить Обучение и Магазин, почта, Instagram, VK, Telegram, ссылки заказа и оплаты |
| Публикация | git commit + push — дальше TimeWeb обновит сайт сам |

Данные: `assets/content.js` (тексты, магазин, обучение, настройки) и
`assets/shoots.js` (съёмки). Страницы читают их через `assets/bind.js`,
настройки перекрывают `config.js`. Перед каждым сохранением прежние файлы
копируются в `admin/backups/` (в git не идут). Папка `admin/` на хостинге
закрыта через `.htaccess`: без локального server.py она всё равно не работает.

`assets/config.js` (подключён в `<head>`): `sections.learning` / `sections.shop`
— включить или скрыть раздел в один шаг; `lessonCheckout` — платёжная ссылка
видеоурока; `printOrder` — ссылка заказа отпечатка. Пока ссылки пусты, обе
кнопки открывают письмо на `email` с темой. Ключей и секретов в config.js
не класть — файл публичный.

Новые кадры (`img/p*.jpg`, `s*.jpg`, `van-*.jpg`, `zn-cover-lg.jpg`) собраны
из `../02 Сайт/photos` — выбор провизорный, финальный делает Ваня.

Статическая главная. Ни сборки, ни зависимостей: открывается как обычный файл,
кладётся на любой статик-хостинг как есть.

```
index.html          вся разметка главной — сетка во всю ширину экрана (основа)
index-centered.html альтернативная центрированная раскладка, noindex, для сравнения
assets/base.css     токены и примитивы DESIGN.md
assets/centered.css только геометрия центрированной альтернативы
assets/site.css     компоненты главной
assets/photo-tilt.css
assets/photo-tilt.js «кадр в руках» — DESIGN.md § 7.9, значения меняются только здесь
assets/site.js      раскрытие кадров, счётчики, навигация, инерция скролла, герой
assets/config.js    адрес видео и постера — единственное место, где их менять
img/                кадры (18 файлов, 1,3 МБ)
video/hero.webm     запасное видео героя, играет пока config.js пуст
```

Закон проекта — `../DESIGN.md`. При расхождении приоритет у него.

## Локально

```bash
python -m http.server 8000
```

Файлом (`file://`) тоже открывается, но видео и шрифты ведут себя по-разному —
для проверки лучше сервер.

## Видео героя

`assets/config.js` → `heroVideo`. Пока пусто, играет `video/hero.webm` из репозитория.
Как поставить внешний адрес и почему — в `../DEPLOY.md`.

## Что ещё не подставлено

`[ПОЧТА]`, `[ТЕЛЕФОН]`, `[ДАТА]`, `[МЕСТО]`, `[ЦЕНА]`, `[МЕСТ]` — по DESIGN.md § 13
значения не выдумываются. Ссылки разделов и `/en/` ведут на якоря: внутренних
страниц (история, мастер-класс, заявка) в этом репозитории пока нет, их макеты
лежат в `../canvas`.

## Две раскладки

**`index.html` — основа сайта.** Сетка из 12 колонок тянется на всю ширину
вьюпорта (`--max-width: none`), поле страницы 64px / 20px и одинаково для
текста и для кадров. Это зафиксировано в `../DESIGN.md` §5, вместе с отменой
техники «вылет за край». В продакшн идёт именно она.

**`index-centered.html` — альтернатива.** Прежняя раскладка: колонка максимум
1600px по центру, вылет за край работает, подписи под кадрами на месте.
Подключает `assets/centered.css`, помечена `noindex`, держим для сравнения.
Правки главной сюда не переносятся — это снимок состояния на 2026-09-05.

## Что изменилось на главной 2026-09-05 (вечер)

Всё внесено в `../DESIGN.md`, здесь — короткий список:

1. сетка во всю ширину экрана (§5), «вылет за край» отменён;
2. подписи под кадрами убраны везде (§6);
3. кадры крупнее: по умолчанию 6 колонок — половина экрана — и
   преимущественно горизонтальные, 3:2 (§5, §6);
4. в «Первом взгляде» один кадр вместо двух в ряд; в манифесте кадров нет;
   в «Плёнке» все три кадра горизонтальные;
5. кадр во весь экран живёт без анимации — ни маски, ни наклона (§7.8-бис,
   правило на весь сайт);
6. фильтры историй стоят по левому краю таблицы, в той же правой половине
   сетки; блок «Говорят пары» — той же ширины, что таблица;
7. счётчики в «Коротко» крупнее: clamp(80px, 13vw, 260px) (§4);
8. между секциями больше воздуха: 256px / 128px (§5);
9. мастер-класс — вторая тёмная секция сайта после футера: чёрный холст во
   всю ширину, отступы 192px, кадр на половину экрана, кнопка белым по
   чёрному (§3);
10. выделение текста — чёрное, алый акцент отменён (§3).

## Сетка по кнопке

Внизу слева — служебная кнопка «Сетка»: показывает те же 12 колонок, gutter
и поле страницы, на которых стоит сайт. То же самое — клавишей `G`.
Состояние живёт в `sessionStorage`. Это инструмент вёрстки, не часть дизайна;
перед сдачей клиенту кнопку и оверлей можно удалить одним блоком в
`index.html`, `site.css` и `site.js` — они помечены комментариями.
